Task context starter prompt

Purpose

A reusable message template that helps you describe your goal, background, constraints and desired output before an AI starts a task.

Go to prompt
Works with
Any AI assistant that accepts text prompts
Format
Plain text (.txt)

Expected outcomes

  • One message stating what you want, the background the assistant needs, your constraints and the format you want back.
  • The assistant is asked to check for important missing details before answering.

How to use it

  1. Select Copy prompt below. If you download the .txt file instead, open it and copy the text.
  2. Paste the text into your AI assistant’s message box.
  3. Replace each bracketed field with your own details. For example, replace [specific goal] with the task you want completed.
  4. Send the message. Answer any follow-up questions, then review the response.

What you need

  • An AI assistant that accepts text input.
  • Your goal, relevant background, constraints and preferred output format.

The prompt

I want to [specific goal].
Here’s the relevant context: [background].
My constraints are [time, tools, or limits].
A useful result would look like [format or example].
Ask me about any missing information that would materially change your answer.

Things to know

  • This prompt organizes your task brief. It does not verify facts or guarantee a correct answer; review the assistant’s response before using it.

Keep private information out unless you understand and accept how your chosen tool handles it.
