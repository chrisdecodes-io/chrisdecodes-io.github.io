Instructions

Use instructions to set rules for how an AI assistant should respond, such as its tone, answer format or checks to follow. Save them for use within a chat or project.

How to use instructions

No instruction sets are available yet. When one is added:

  1. Open an instruction set and check which app it supports and where its rules apply.
  2. Adapt the rules to your needs. Save or paste them in the location named on the resource page, such as project instructions or the start of a chat.
  3. Give the assistant your task, then check that its response follows the rules.
